# KitabuPOS UX/UI Audit & Action Plan

| Screen | Problem | Fix | Effort |
| :--- | :--- | :--- | :---: |
| **POS** | Scanner focus lost on clicks/modal close; exact barcode scan requires Enter/click; no sound/flash feedback. | Keep search input permanently focused; auto-add to cart on exact barcode/ISBN match; audio beep & visual flash on scan (green=success, amber=not found). | M |
| **POS** | Category chips truncated at 5 via `.slice(0, 5)`; prices lack large tabular monospace numbers; touch targets <44px. | Horizontally scrollable chips with ALL categories; >=44px touch targets; large monospace tabular pricing; min 14px body text. | M |
| **POS** | Cart lacks inline quantity typing, inline discount editing, stock level warnings, hold/resume carts, and undo-remove. | Inline quantity stepper + direct number typing; inline line item discount; stock warning badge ("2 left"); multi-cart Hold/Resume; undo remove toast. | M |
| **POS** | Checkout is mouse-heavy; confetti causes delay; no M-Pesa format/duplicate validation; split tender remainder not calculated. | Keyboard-first checkout (Enter/Esc/number keys); instant inline confirmation (no confetti freeze); 10-char M-Pesa validation & duplicate check; split remainder auto-fill; shortcut cheat-sheet (`?`). | M |
| **Global UI** | Ad-hoc styles, lacking uniform design tokens, missing shared primitives, small click targets, no focus rings. | Centralize design tokens in Tailwind `@theme`; build shared Button, Input, Modal, ConfirmDialog, EmptyState, DataTable, and StatusBadge components with WCAG AA contrast. | M |
| **Global UI** | `select-none` blocks copying receipt numbers & M-Pesa codes; PWA prompts appear inside Electron. | Remove `select-none` from copyable text; hide PWA install banners/prompts inside Electron environment. | S |
| **Dashboard** | Missing cash vs M-Pesa split; low-stock items cannot be ordered directly; backup age not highlighted. | Lead with today's sales and payment split; actionable low-stock list with "Create Purchase Order"; backup freshness card turning red after 2 days. | M |
| **Inventory** | No inline stock/price adjustments; no bulk archive/categorize; CSV import lacks row error reporting; no barcode printing. | Add inline price/stock edit with audit reason; bulk select checkboxes with batch actions; row-by-row CSV error display; thermal barcode label print modal. | M |
| **Purchases** | Ledger lacks Draft -> Received -> Paid progression; cannot mark pending orders as received or record supplier payments. | Add 3-stage purchase status flow with "Receive Goods" and "Record Payment" ledger actions. | M |
| **Expenses** | Manual date selection without presets; lacks quick cash denomination buttons for transport/casuals. | Add quick amount buttons (KES 50, 100, 200, 500, 1000); date presets (Today, Yesterday); category breakdown. | S |
| **Reports** | No "Yesterday" filter; uses UTC for dates rather than Nairobi timezone; missing Cashier End-of-Day (Z-Report). | Add Nairobi date helpers, Yesterday/Today/Week/Month presets; create Cashier End-of-Day Z-Report with print layout & CSV export. | M |
| **Users / Login** | Default PIN pre-filled ('1234'); seeded accounts lack forced password change; no password visibility toggle; no login rate limit. | Remove default PIN prefill; mask PIN; add show/hide password toggle; enforce password change on first login for default accounts; rate limit failed attempts with cooldown. | M |
| **Settings** | Flat layout with messy tabs; destructive wipe/restore actions lack typed confirmation; no live receipt preview. | Reorganize into 6 clean tabs (Shop, Receipt, Payments, Security, Backup, Data); live receipt preview; typed confirmation ("CONFIRM") for destructive actions. | M |
| **First-Run Wizard** | 6 overly long steps with repetitive inputs and no CSV import option. | Streamline to 4 high-value steps (Shop Identity, Payments & Till, Admin Security, Optional CSV Import) with skip capability and progress bar. | M |
